# M2 — round-2 source list and query set

**Artifact**: `docs/RSA-Documents/track-a-round2-sources.json` (new).

## What it holds

- `schema_version`, `source_of_record` (ticket #60), the `plan` pointer, and a `note` that says
  why `host` names the discovery host for a search source while the licence and the province of
  each candidate are resolved from its host.
- `discovery` — the channel table: agent-reach's Jina Reader channel over a search engine, the
  engines that are unavailable and why, the politeness rules (1 request/second per host via
  `src/discovery/ratelimit.ts`), and the model-triage statement.
- `split_rule` — mirrored from `docs/RSA-Documents/track-a-sources.json`: QC + AB are the test
  geography, a licence verdict that is not CLEAR never enters train or test. The ticket's phrase
  "the held-out prairie province" is read as Alberta per `scripts/harvest-track-a.ts:38`.
- `hash_rule` — the three known-hash sources and the "downloaded in full and then discarded"
  wording the gate implies.
- `byte_cap` — 5 GiB cumulative, 100 MiB per document.
- `source_types` — the closed seven-type taxonomy.
- `sources[]` — seven entries, one per family, each with `id`, `host`, `family`, `source_type`,
  `strategy: "candidate-list"`, `queries[]`, `licence_default`, `stage_hint`, `ca_province_hint`,
  `doc_type_hint`, `max_downloads` and a `discovery` block naming the channel.
- `host_licences` — the three hosts with a published open licence (Alberta OGL, Montreal Liibre,
  Open Government Licence - Canada). Every other host falls back to the source's declared
  RESTRICTED default.
- `province_hints` — host to province, so a candidate's province is known without reading it.
- `unfillable[]` — the 13 Track A families, carried forward with this round's verification notes.

## Acceptance

- Every source carries a `source_type` from the closed set — yes.
- Every source carries a `licence_default` and at least one query — yes.
- The unfillable array carries the 13 families forward — yes.
