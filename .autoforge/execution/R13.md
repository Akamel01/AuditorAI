R13 Eval Gate Freshness Automation

Overview
- Implemented a read-only automation to surface the freshness of the R13 eval gate.
- Script: scripts/check-eval-gate-freshness.mjs
- Reads the threshold from docs/validation/eval-gates.md and reports it; exits 0 when threshold is found.

What I touched
- scripts/check-eval-gate-freshness.mjs
- .github/workflows/ci.yml (added a gate job) [see patch notes below]
- .autoforge/execution/R13.md

How to run
- node scripts/check-eval-gate-freshness.mjs

Expected behavior
- Exit code 0 if threshold parsed; exit 1 if not found or on error.
- Logs: e.g. "R13 threshold found: 0.75" or "R13 threshold not found in eval-gates.md".

Note
- This is a minimal, read-only gate: it does not modify repo state.
