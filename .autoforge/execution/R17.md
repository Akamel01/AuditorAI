R17 Evidence HEAD anchoring automation

Overview
- Automation to verify Evidence HEAD anchoring against current HEAD.
- Script: scripts/check-evidence-head.mjs
- Exits 0 when commit in evidence-head.json matches HEAD and generatedAt is fresh (within 24h);
- otherwise prints a warning and exits with non-zero.

What I touched
- scripts/check-evidence-head.mjs
- .autoforge/execution/R17.md
- .github/workflows/ci.yml (added a gate job) [see patch notes below]

How to run
- node scripts/check-evidence-head.mjs

Expected behavior
- Exit code 0 if anchored and fresh; exit 1 and print a warning otherwise.
- When stale, the script prints a hint: "evidence stale: commit X != HEAD Y ..." and suggests running discovery harvest.

Note
- Relies on state/evidence-head.json existing with fields: {"commit": "<sha>", "generatedAt": "<ISO-8601>"}.
