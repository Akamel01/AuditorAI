# Architecture Decision Records

ADRs record decisions that are **hard to reverse**, **surprising without context**, and
**the result of a real trade-off**. Anything less belongs in `docs/decisions/` or the
Wayfinder map.

- File name: `NNNN-short-slug.md` (zero-padded, sequential).
- Status lifecycle: `Proposed → Accepted → Superseded by NNNN`.
- Every ADR is registered in `state/decision-registry.json` after acceptance.
