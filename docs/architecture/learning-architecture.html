End-to-end graph: raw sources → audit → learning loop

Every road-safety audit runs the deterministic 11-node pipeline. One node is AI-bounded and produces CandidateFinding[] for human adjudication. Improvement happens not by retraining weights, but by versioning prompts, few-shot exemplars, evidence registry, and policy packs — all deterministic, auditable, and reversible. The AiAdapter seam makes prompting → fine-tune a one-line config change when data unlocks it.

Data flywheel rule: Every auditable production run logs a CandidateOutcome (Phase 1). Accepted + edited candidates curate the few-shot store. Gated fixtures promote cells. No separate “data team” — the flywheel is a byproduct of use.
Fine-tune gate (Phase 4): 500+ CandidateOutcomes / jur / stage and promotion-rate plateau and latency/cost or offline need. Until then, the same AiAdapter interface keeps you on prompting — one env var flips to a local model.

03 — One-line adapter swap: prompting → fine-tune

Current — prompting (Zen)

AI_ADAPTER=zen
const ADAPTER_FACTORIES = {
  off: () => new OffAiAdapter(),
  zen: () => new ZenAiAdapter({
    apiKey: process.env.OPENCODE_API_KEY,
    baseUrl: process.env.AI_BASE_URL,
    model: process.env.AI_MODEL, // x-preview-f-free
    effort: process.env.AI_EFFORT ?? "high",
  }),
};

Future — fine-tuned (same interface)

AI_ADAPTER=ft-uk-s1
import { FineTunedAdapter } from "@/lib/ai-finetuned-adapter";
ADAPTER_FACTORIES["ft-uk-s1"] = () =>
  new FineTunedAdapter({
    modelPath: process.env.FT_MODEL_PATH,   // ./models/auditor-uk-s1-lora
    tokenizerPath: process.env.FT_TOKENIZER_PATH,
  });
// generateCandidates(audit, images, notes, vocab)
// → CandidateFinding[] — identical contract, validated same way
Pipeline code (generateCandidatesLive), schema validation, hallucination checks, adjudication, and eval-gates are unchanged. The adapter is swappable at the seam — no pipeline edits, no schema edits, rollback is one env var.

04 — What is actually learned

Canonical target: CandidateFinding — the only learned artifact

structured intermediate

The model does not learn: stage eligibility, input normalization, rule firing, evidence lookup, report assembly, wording discipline, or ODD gating — all deterministic. It learns only the gap a rule set cannot express: hazard → safety-concern reasoning with proportionate recommendations.

Every normative claim cites a registry ID. validateCandidateAtBoundary enforces it. Candidates never become Findings without explicit promotion (ADR-0006).
