# Decision Log

Lightweight decisions that are **not** ADR-worthy (reversible, unsurprising, or
low-stakes) but still need to be findable: ordering, naming, tooling minutiae.
Format: date, decision, one-line rationale, decider node.

ADRs live in `docs/adr/`. Wayfinder ticket resolutions live in the map tickets.
This log is for everything in between.
