# Validation Records

Results of validation passes, separated into:

- **Technical validation** — does the system behave as designed?
- **Domain validation** — does the workflow resemble a defensible Road Safety Audit
  process (Stage 0/1/2 per jurisdiction, missing/conflicting data, report generation)?

Each record: date, validator node, scope, method, result, follow-ups. Validation state
is mirrored in `state/validation-state.json`.
