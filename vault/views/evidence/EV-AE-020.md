# EV-AE-020

Abu Dhabi risk semantics are qualitative: each finding must state the location, nature, and the type of crashes considered likely to result (the specimen report uses types such as side-swipe, rear shunt, overshoot and collisions with non-motorised users), recommendations are advisory ('the auditor cannot give instructions') and must be proportionate and viable, 'monitor' recommendations are restricted to identified manoeuvres or causation factors with a named owner, and the manual defines no numeric severity/probability scoring matrix.
