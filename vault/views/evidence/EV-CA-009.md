# EV-CA-009

Alberta Transportation requires road safety audits on federally funded projects regardless of project type as required by Transport Canada, and prescribes required audit stages varying by project type and location (e.g., interchanges, widening, intersection improvements, ring roads, reconstruction/realignment) through a summary requirements matrix.
