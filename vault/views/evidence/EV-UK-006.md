# EV-UK-006

GG 119 clause 2.1-2.3 makes RSA applicable wherever there are physical changes to the highway that impact road user behaviour or the outcome of a collision on the trunk road and motorway network regardless of procurement method, states RSA shall not apply where there is no such impact, requires the Overseeing Organisation to record an exemption file note where RSA is not applied, and excludes like-for-like maintenance schemes from RSA.
