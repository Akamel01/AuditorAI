# EV-UK-016

GG 119 requires a RSA response report for stages 1, 2 and 3 (none for Stage 4), managed by the design organisation in collaboration with the Overseeing Organisation, containing a decision log reiterating every problem and recommendation in which the design organisation must accept, accept with alternative solution, or disagree with reasoning for each item, an Overseeing Organisation response and agreed action for each problem, signatures from both organisations, and recommends finalisation within one month of issue of the RSA report.
