# EV-US-006

The FHWA Road Safety Audit Guidelines organize audit applicability by named project phases rather than numbered stages: pre-construction phase prompt lists cover Planning Stage Audit, Preliminary Design Stage Audit, and Final Design Stage Audit; construction phase prompt lists cover Work Zone Traffic Control Plan Audit and Pre-Opening Stage Audit; the post-construction phase covers Existing Road Audit; and a separate Land Use Development Proposals Audit applies to development projects, with the prompt lists themselves numbered 1 through 7.
